# routes/tests/

Tests pytest pour les routes de l'API.

⚠️ Actuellement, ces tests sont des placeholders (`assert True`) et ne couvrent pas
réellement les endpoints. À compléter avec des appels via le client de test Flask
(`app.test_client()`) pour vérifier les codes de statut et le contenu des réponses.

```bash
pytest routes/tests/
```
